২. EAS CLI দিয়ে ক্লাউড বিল্ড করার পূর্ণাঙ্গ গাইড (ম্যাক ছাড়াই Android + iOS বিল্ড):

আমরা আপনার প্রোজেক্টের রুটে একটি প্রোডাকশন-রেডি eas.json ফাইল তৈরি করে দিয়েছি, যা সরাসরি Bare React Native CLI প্রোজেক্ট সাপোর্ট করে।

ধাপ ১: EAS CLI ইনস্টল করুন

আপনার টার্মিনালে নিচের কমান্ডটি রান করুন:

bash
npm install -g eas-cli
ধাপ ২: ফ্রি Expo অ্যাকাউন্ট খুলে লগইন করুন
ব্রাউজারে expo.dev/signup
-এ গিয়ে একটি ফ্রি অ্যাকাউন্ট তৈরি করুন।
আপনার টার্মিনালে রান করুন:
bash
eas login
(আপনার ইমেইল ও পাসওয়ার্ড দিয়ে লগইন করুন)
ধাপ ৩: প্রোজেক্টটি EAS-এর সাথে লিংক করুন

টার্মিনালে রান করুন:

bash
eas init

(এটি স্বয়ংক্রিয়ভাবে আপনার প্রোজেক্ট শনাক্ত করে এক্সপো অ্যাকাউন্টের সাথে যুক্ত করবে)

৩. কীভাবে ক্লাউড থেকে অ্যাপ বিল্ড করবেন:
ক. অ্যান্ড্রয়েড সরাসরি টেস্টযোগ্য APK বিল্ড করতে (Installable APK):
bash
eas build -p android --profile preview
কী ঘটবে? কোডটি EAS ক্লাউড সার্ভারে চলে যাবে, সেখানে স্বয়ংক্রিয়ভাবে বিল্ড হয়ে টার্মিনালে একটি ডাউনলোড লিঙ্ক ও QR Code দিবে। মোবাইলের ক্যামেরা দিয়ে স্ক্যান করলেই সরাসরি APK ডাউনলোড হয়ে যাবে!
খ. অ্যান্ড্রয়েড গুগল প্লে-স্টোরের জন্য AAB বিল্ড করতে (মাত্র ২৫-৩৫ MB সাইজ):
bash
eas build -p android --profile production
গ. আইওএস (iOS) বিল্ড করতে (ম্যাক পিসি ছাড়া ক্লাউড ম্যাক দিয়ে):
bash
eas build -p ios --profile preview
ম্যাজিক: আপনার নিজের ম্যাক পিসি না থাকলেও Expo-র নিজস্ব ক্লাউড অ্যাপল ম্যাক সার্ভারে আপনার কোড বিল্ড হবে এবং আইফোনে সরাসরি ইনস্টল করার লিঙ্ক দিয়ে দেবে!
৪. লোকাল রিলিজ APK টেস্ট করার কমান্ড:

আপনি যদি নিজের পিসিতেই অপ্টিমাইজড রিলিজ এপিকে বিল্ড করতে চান:

bash
cd android && ./gradlew assembleRelease && cd ..

বিল্ড শেষে android/app/build/outputs/apk/release/ ফোল্ডারে অপ্টিমাইজড এপিকে পেয়ে যাবেন।
